# Agent Documentation Index

These guides describe how to work safely and consistently in the
`ecommerce-client` repository.

## Intended readers

- Developers learning the project
- Coding agents implementing approved milestones
- Reviewers checking focused changes
- Maintainers onboarding contributors

## How the guides fit together

1. Start with [WORKFLOW.md](WORKFLOW.md) for the required development loop.
2. Use [PROJECT_MAP.md](PROJECT_MAP.md) and [ARCHITECTURE.md](ARCHITECTURE.md)
   to locate code and understand current behavior.
3. Use [COMMANDS.md](COMMANDS.md) and [TESTING.md](TESTING.md) before
   verification.
4. Use [CODING_STANDARDS.md](CODING_STANDARDS.md) and
   [CHANGE_GUIDE.md](CHANGE_GUIDE.md) while implementing changes.
5. Use [REVIEW_CHECKLIST.md](REVIEW_CHECKLIST.md) before reporting work.
6. Check [DECISIONS_AND_GAPS.md](DECISIONS_AND_GAPS.md) before relying on
   undocumented behavior.

The canonical project-specific workflow and safety rules are in
[AGENT.md](../../AGENT.md). [AGENTS.md](../../AGENTS.md) is only a pointer to
that file. Changing milestone status and verification results are maintained
in [PROJECT_STATUS.md](../PROJECT_STATUS.md).
