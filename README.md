# Ecommerce Client

## Description

Simple Angular customer-facing e-commerce client for the Order Processing System.

## Technology

Angular
TypeScript
RxJS

## Development

npm install

npm start

## URL

http://localhost:4200

## Backend

Order Service:
http://localhost:8080

Fake Payment Gateway:
http://localhost:8081

Important:

The Angular client communicates only with the Order Service.
